# PandasData-Analysis

About the Project

This project is a comprehensive data analysis study conducted in a Jupyter Notebook environment using Python and the Pandas library. Datasets from different sources and formats, including JSON, Excel, and SQL, were read and combined into a single analytical workflow. After data cleaning and preprocessing, date formats were converted and standardized, and time-series-focused analyses were performed through daily, monthly, and yearly groupby operations. This made it possible to uncover trends, seasonal changes, and key relationships in the data, and the findings are presented in a clear and interpretable way. The project demonstrates practical skills in multi-source data ingestion, date-based grouping, and exploratory data analysis (EDA) with Pandas.
